# 🛍️ Ecommerce Frontend

This is the **frontend** for an Ecommerce application built with React. It provides the user interface for browsing products, adding to cart, viewing product details, and more.

---

## ✨ Features

- Product listing and details  
- Add / remove items from cart  
- View cart summary and checkout flow (frontend only)  
- Responsive layout for desktop & mobile  
- Built using Create React App

---

## 🛠️ Tech Stack
  **Technologies Used** HTML , css , javascript , react
- **Framework / Library:** React  
- **Styling:** CSS 
- **Tooling:** Create React App
